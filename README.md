## Descripción

Sitio web sencillo creado únicamente con HTML. Sirve para practicar el trabajo con ramas independientes y su fusión mediante Pull Requests.

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/oblancoh/mi-proyecto-web.git
   ```
2. Entra en la carpeta:
   ```bash
   cd mi-proyecto-web
   ```
3. Abre `index.html` en tu navegador.
